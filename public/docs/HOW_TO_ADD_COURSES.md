# كيفية إضافة دروس ومستويات جديدة

## الخطوات

### 1. إنشاء ملف المنهج

أنشئ ملف JSON جديد باتباع القالب في `course-template.json`.

### 2. ملء البيانات

- اختر معرّف فريد (مثلاً: `level-01`, `python-basics`, `web-intro`)
- اكتب العنوان والوصف
- حدد رقم المستوى والترتيب
- أضف الوحدات والدروس

### 3. التحقق من الصحة

تأكد من:
- جميع الحقول المطلوبة موجودة
- `schemaVersion` هو `"1.0"`
- المعرّفات فريدة
- الاختبارات لها خيارات وإجابة صحيحة

### 4. الاستيراد

1. افتح المنصة
2. اذهب إلى "إدارة المناهج"
3. اضغط "اختر ملف JSON"
4. اختر الملف
5. راجع المعاينة
6. أكد الاستيراد

### 5. التحديث

لتحديث مستوى موجود:
- استخدم نفس `id`
- استورد الملف الجديد
- سيتم تحديث المحتوى مع الحفاظ على تقدم الطالب

## مثال عملي

```json
{
  "id": "python-basics",
  "title": "أساسيات بايثون",
  "description": "تعلم أساسيات لغة بايثون من الصفر",
  "levelNumber": 1,
  "order": 1,
  "language": "ar",
  "schemaVersion": "1.0",
  "estimatedMinutes": 180,
  "units": [
    {
      "id": "unit-intro",

      "order": 1,
      "lessons": [
        {
          "id": "lesson-what-is-python",
          "title": "ما هي بايثون؟",

          "order": 1,

```

## نصائح

- ابدأ بالمستويات الأساسية أولاً
- اجعل الدروس قصيرة ومركزة (5-15 دقيقة لكل درس)
- أضف أهداف تعليمية واضحة
- استخدم التنبيهات والملاحظات لتوجيه الطالب
- أضف تمارين تطبيقية بعد كل مفهوم
- اجعل الاختبارات متنوعة وتغطي المفاهيم الأساسية
